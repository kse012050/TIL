# user-select
CSS의 사용자가 텍스트를 선택할 수 있는지 여부를 제어하는 속성입니다.  
텍스트 상자를 제외하고 chrome으로 로드 된 컨텐츠에는 영향을 미치지 않습니다. (즉, 브라우저에서 제공되는 것은 해당 X?)

## none
요소 및 해당 하위 요소의 텍스트를 선택할 수 없습니다.  
점을 유의 ```Selection``` 객체가 이러한 요소를 포함 할 수 있습니다.

## auto
사용 된 값은 ```auto``` 다음과 같습니다.
- 온 ```::before``` 및 ```::after``` 유사 요소는 사용 된 값은 ```none```
- 요소가 편집 가능한 요소 인 경우 사용 된 값은 ```contain```
- 그렇지 않으면, ```user-select``` 이 요소의 상위 ```all``` 에서 사용 된 값이 인 경우 사용 된 값은 ```all```
- 그렇지 않으면, ```user-select``` 이 요소의 상위 ```none``` 에서 사용 된 값이 인 경우 사용 된 값은 ```none```
- 그렇지 않으면 사용 된 값은 ```text```
> 이게 무슨 말이야?

## text
텍스트는 사용자가 선택할 수 있습니다.

## all
요소의 내용은 원자 적으로 선택되어야합니다. (원자적?)  
만약 선택이 요소의 일부를 포함한다면, 선택은 모든 자손을 포함한 전체 요소를 포함해야합니다.  
하위 요소에서 더블 클릭 또는 컨텍스트 클릭이 발생한 경우 이 값을 가진 가장 높은 조상이 선택됩니다.

## contain
요소 내에서 선택을 시작하도록합니다.  
그러나 선택은 해당 요소의 경계에 포함됩니다.

## element
```contain```와 동일합니다.
