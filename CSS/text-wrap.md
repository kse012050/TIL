# text-wrap
text-wrap CSS 단축 속성은 요소 내부의 텍스트가 래핑되는 방식을 제어합니다. 다양한 값은 다음을 제공합니다.  
  
- 인쇄상의 개선(예: 구분된 제목 전체에 걸쳐 줄 길이의 균형 조정)
- 텍스트 줄 바꿈을 완전히 끄는 방법입니다.    
  
> __참고:__ 공백 축소 속성과 텍스트 줄 바꿈 속성은 공백 단축 속성을 사용하여 함께 선언할 수 있습니다.  
  
## 예
[MDN 공식 사이트](https://developer.mozilla.org/en-US/docs/Web/CSS/text-wrap)

## 구성 속성
이 속성은 다음 CSS 속성의 약칭입니다.  
- text-wrap-mode
- text-wrap-style

## 문법
~~~css
/* Keyword values */
text-wrap: wrap;
text-wrap: nowrap;
text-wrap: balance;
text-wrap: pretty;
text-wrap: stable;

/* Global values */
text-wrap: inherit;
text-wrap: initial;
text-wrap: revert;
text-wrap: revert-layer;
text-wrap: unset;
~~~
text-wrap 속성은 아래 값 목록에서 선택한 단일 키워드로 지정됩니다.

### 값
#### wrap
오버플로를 최소화하기 위해 텍스트는 적절한 문자(예: 공백, 공백 구분 기호를 사용하는 영어와 같은 언어)에서 줄 바꿈됩니다. 이것이 기본값입니다.

#### nowrap
텍스트가 여러 줄에 걸쳐 줄바꿈되지 않습니다. 새 줄로 넘어가는 대신 포함된 요소가 오버플로됩니다.

#### balance
텍스트는 각 줄의 문자 수 균형을 가장 잘 맞추는 방식으로 래핑되어 레이아웃 품질과 가독성을 향상시킵니다. 문자 수를 세고 여러 줄에 걸쳐 균형을 맞추는 것은 계산 비용이 많이 들기 때문에 이 값은 제한된 수의 줄(Chromium의 경우 6개 이하, Firefox의 경우 10개 이하)에 걸쳐 있는 텍스트 블록에 대해서만 지원됩니다.

#### pretty
사용자 에이전트가 속도보다 더 나은 레이아웃을 선호하는 느린 알고리즘을 사용한다는 점을 제외하면 랩과 동일한 동작이 발생합니다. 이는 성능보다 좋은 타이포그래피가 선호되는 본문 카피용으로 사용됩니다(예: 고아 수를 최소한으로 유지해야 하는 경우).

#### stable ( 아직 지원 X )
사용자가 내용을 편집할 때 편집 중인 줄 앞에 오는 줄이 전체 텍스트 블록을 다시 감싸는 것이 아니라 정적으로 유지된다는 점을 제외하면 줄바꿈과 동일한 동작이 발생합니다.

## 설명
단락(<p>) 또는 제목(<h1>–<h6>)과 같은 콘텐츠 블록 내에서 텍스트가 여러 줄로 흐를 수 있는 방법에는 두 가지가 있습니다. 이는 사용자가 제어하는 ​​강제 줄 바꿈과 브라우저가 제어하는 ​​소프트 줄 바꿈입니다. text-wrap 속성을 사용하면 브라우저에 소프트 라인 분리를 제어하는 ​​방법을 묻는 메시지를 표시할 수 있습니다.  
  
텍스트 줄바꿈에 대해 선택하는 값은 스타일 지정을 예상하는 텍스트 줄 수, 텍스트 내용 편집 가능 여부, 모양이나 성능의 우선순위를 정해야 하는지 여부에 따라 달라집니다.  
  
스타일이 지정된 콘텐츠가 제목, 캡션 및 인용부호와 같이 짧은 줄 수로 제한되는 경우 text-wrap: Balance를 추가하여 각 줄의 문자 수 균형을 맞추고 레이아웃 품질과 가독성을 향상시킬 수 있습니다. 브라우저는 이 속성의 영향을 받는 줄 수를 제한하므로 이 값이 성능에 미치는 영향은 미미합니다.  
  
더 긴 텍스트 섹션의 경우 text-wrap: Pretty를 사용할 수 있습니다. Pretty는 성능에 부정적인 영향을 미치므로 레이아웃이 속도보다 더 중요한 경우 긴 텍스트 블록에만 사용해야 합니다.  
  
안정적인 값은 콘텐츠 편집이 가능한 콘텐츠에 사용될 때 사용자 경험을 향상시킵니다. 이 값은 사용자가 텍스트를 편집하는 동안 편집 중인 영역의 이전 줄이 안정적으로 유지되도록 보장합니다.
