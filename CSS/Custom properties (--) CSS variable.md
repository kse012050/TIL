# Custom properties (--) CSS variable
-- 와 같이 접두사가 붙은 속성 이름은 함수를 사용하여 다른 선언에 사용할 수 있는 값이 포함된 사용자 지정 속성을 ```--example-name``` 나타냅니다  

사용자 정의 속성은 선언 된 요소의 범위를 정하고 캐스케이드에 참여합니다. 이러한 사용자 정의 속성의 값은 계산식 알고리즘에 의해 결정된 선언의 값입니다.  

## ```<declaration-value>```
이 값은 시퀀스에 허용되지 않는 토큰이 없는 한 하나 이상의 토큰 시퀀스와 일치합니다.  
유효한 선언이 가치로 가질 수 있는 것의 전체를 나타냅니다.  

> 참고 : 사용자 정의 속성 이름은 대소 문자를 구분 ```--my-color``` 합니다.  
> ```--My-color``` 에 대한 별도의 사용자 정의 속성으로 취급됩니다.
