# clamp()
clamp() CSS 함수는 정의된 최소 경계와 최대 경계 사이의 값 범위 내에서 중간 값을 고정합니다. 이 함수는 최소값, 선호하는 값, 허용되는 최대값의 세 가지 매개변수를 사용합니다.  
  
[Fluid Typography의 코드](https://css-tricks.com/snippets/css/fluid-typography/)와 동일한 효과를 가지지만 한 줄에 있고 미디어 쿼리를 사용하지 않습니다.

## 문법
~~~css
/* 정적 값 */
width: clamp(200px, 40%, 400px);
width: clamp(20rem, 30vw, 70rem);
width: clamp(10vw, 20em, 100vw);

/* 계산된 값 */
width: clamp(min(10vw, 20rem), 300px, max(90vw, 55rem));
width: clamp(100px, calc(30% / 2rem + 10px), 900px);
~~~

## 매개변수
clamp(min, val, max) 함수는 쉼표로 구분된 세 개의 표현식을 매개변수로 허용합니다.

### min
최소값은 가장 작은(가장 음수) 값입니다. 이는 허용되는 값 범위의 하한입니다. 기본 값이 이 값보다 작으면 최소값이 사용됩니다.

### val
선호되는 값은 결과가 최소값과 최대값 사이에 있는 한 해당 값이 사용되는 표현식입니다.

### max
최대값은 기본 설정 값이 이 상한보다 큰 경우 속성 값이 할당되는 가장 큰(가장 긍정적인) 표현식 값입니다.  
  
표현식은 수학 함수(자세한 내용은 calc() 참조), 리터럴 값, 유효한 인수 유형(예: <length>)으로 평가되는 기타 표현식 또는 중첩된 min() 및 max() 함수일 수 있습니다. 수학 표현식의 경우 calc() 함수 자체를 사용하지 않고도 덧셈, 뺄셈, 곱셈, 나눗셈을 사용할 수 있습니다. 필요한 경우 괄호를 사용하여 계산 순서를 설정할 수도 있습니다.  
  
표현식의 각 값에 대해 서로 다른 단위를 사용할 수 있으며 인수를 구성하는 수학 함수에서도 서로 다른 단위를 사용할 수 있습니다.  
  
기능을 사용하는 동안 다음 측면을 염두에 두십시오.
- 자동 및 고정 레이아웃 테이블 모두의 테이블 열, 테이블 열 그룹, 테이블 행, 테이블 행 그룹 및 테이블 셀의 너비 및 높이에 대한 백분율을 포함하는 수학 표현식은 자동이 지정된 것처럼 처리될 수 있습니다.
- max() 및 min() 함수를 표현식 값으로 중첩하는 것이 허용되며, 이 경우 내부 함수는 단순 괄호로 처리됩니다. 표현식은 완전한 수학 표현식이므로 calc() 함수 자체를 사용하지 않고도 직접 덧셈, 뺄셈, 곱셈, 나눗셈을 사용할 수 있습니다.
- 표현식은 표준 연산자 우선 순위 규칙을 사용하여 더하기( + ), 빼기( - ), 곱하기( * ) 및 나누기( / ) 연산자를 결합한 값일 수 있습니다. + 및 - 피연산자 양쪽에 공백을 넣어야 합니다. 표현식의 피연산자는 모든 <length> 구문 값일 수 있습니다. 표현식의 각 값에 대해 서로 다른 단위를 사용할 수 있습니다. 필요한 경우 괄호를 사용하여 계산 순서를 설정할 수도 있습니다.
- 종종 클램프() 함수 내에서 min() 및 max()를 사용하고 싶을 것입니다.

## 반환 값
clamp(MIN, VAL, MAX)는 max(MIN, min(VAL, MAX))로 확인됩니다.

제공된 매개변수에 따라 함수는 ``<length>``, ``<frequency>``, ``<angle>``, ``<time>``, ``<percentage>``, ``<number>``, or ``<integer>``를 반환합니다.
