#CSS background
CSS 배경 속성은 요소의 배경 효과를 정의 하는데 사용합니다  
  
CSS 배경 속성
+ background-color
+ background-image
+ background-repeat
+ background-attachment
+ background-position

## background-color
background-color 속성은 요소의 배경색을 지정합니다  

CSS를 사용하면 색상은 다음과 같이 지정할 수 있습니다
+ 유효한 색상 이름 - 예 : "red"
+ HEX 값 - 예 : "#ff0000"
+ RGB 값 - 예 : "rgb(255,0,0)"

## background-image
background-image 속성은 요소의 배경으로 사용할 이미지를 지정할 수 있습니다  
기본적으로 이미지는 전체 요소를 포함하도록 반복됩니다

## background-repeat
background-repeat 속성은 가로 및 세로로 이미지를 반복하게 할 수 있습니다  
일부 이미지는 가로 또는 세로로만 반복해야합니다  
+ background-repeat: repeat-x
    + __가로__ 로만 반복
+ background-repeat: repeat-y;
    + __세로__ 로만 반복
+ background-repeat: no-repeat
    + 배경 이미지를 한번만 표시
    + 가로 세로 반복 없음

## background-attachment
배경 이미지를 고정합니다  
(나머지 페이지와 함께 스크롤하지 않습니다)

## background-position
이미지의 위치를 지정해 줄 수 있습니다
+ 보통 right left top bottom 으로 지정해 줍니다
    + 이미지가 시작 되는 위치입니다
+ px % 값으로 지정해 줄 수도 있습니다

## Background - Shorthand property
속기 속성을 사용할 때 속성 값의 순서
+ background-color
+ background-image
+ background-repeat
+ background-attachment
+ background-position

## background
하나의 선선에 모든 배경 속성을 설정 할 수 있습니다

## background-attachment
배경 이미지가 고정되어 있는지 또는 페이지의 나머지 부분과 함께 스크롤 되는지 여부를 설정합니다

## background-clip
배경의 페인트 영역을 지정합니다

## background-color
요소의 배경색을 설정합니다

## background-image
요소의 배경이미지를 설정합니다

## background-origin
배경이미지의 위치를 지정합니다

## background-position
배경이미지의 시작 위치를 설정합니다

## background-repeat
배경이미지를 반복하는 방법을 설정합니다

## background-size
배경이미지의 크기를 지정합니다
