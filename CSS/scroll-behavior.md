# scroll-behavior
CSS의 탐색 또는 CSSOM 스크롤 API에서 트리거 스크롤 할 때 속성은 스크롤 상자의 동작을 설정합니다.

> 사용자가 수행 한 것과 같은 다른 스크롤은 이 속성의 영향을 받지 않습니다.   
>이 속성이 루트 요소에 지정되면 뷰포트에 대신 적용됩니다.   
> ```body``` 요소에 지정된 이 속성은 뷰포트로 전파 되지 않습니다.

## auto
스크롤 상자가 즉시 스크롤 됩니다.

## smooth
스크롤 상자는 사용자 에이전트 정의 시간 동안 사용자 에이전트 정의 타이밍 기능을 사용하여 부드럽게 스크롤 됩니다.  
사용자 에이전트는 플랫폼 규칙을 준수해야합니다.(있을 경우)
