# scroll-margin-top
``scroll-margin-top`` 속성은 이 상자를 스냅포트에 스냅하는 데 사용되는 스크롤 스냅 영역의 상단 여백을 정의합니다. 스크롤 스냅 영역은 변환된 테두리 상자를 가져와서 스크롤 컨테이너의 좌표 공간에서 축 정렬된 직사각형 경계 상자를 찾은 다음, 지정된 아웃셋을 더하여 결정됩니다.

## Try it
[예시 데모](https://developer.mozilla.org/en-US/docs/Web/CSS/scroll-margin-top#try_it)

## Syntax
~~~css
/* <length> 값 */
scroll-margin-top: 10px;
scroll-margin-top: 1em;

/* 전역 값 */
scroll-margin-top: 상속;
scroll-margin-top: 초기값;
scroll-margin-top: 되돌리기;
scroll-margin-top: 레이어 되돌리기;
scroll-margin-top: 설정 안 함;
~~~

## Values
### ``<length>``
스크롤 컨테이너의 상단 가장자리에서부터 시작합니다.

[내용출처 MDN a 태그 스크롤 이동시 유용할 듯](https://developer.mozilla.org/en-US/docs/Web/CSS/scroll-margin-top)
