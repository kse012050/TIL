# object-fit
CSS __object-fit__ 속성은 컨테이너에 맞게 `<img>` 또는 `<video>`의 크기를 조정하는 방법을 지정하는데 사용됩니다.

## object-fit 속성

### fill
기본값, 대체 된 컨텐츠는 요소의 컨텐츠 상자를 채우도록 크기가 조정됩니다.  
필요한 경우 물체가 늘어나기거나 찌그러 질 것입니다.

### contain
교체 된 콘텐츠는 요소의 콘텐츠 상자에 들어가면서 가로 세로 비율을 유지하도록 조정됩니다.

### cover
교체 된 콘텐츠는 요소의 전체 콘텐츠 상자를 채우면서 가로 세로 비율을 유지하도록 크기가 조정됩니다.  
대상에 맞게 개체가 짤립니다.

### none
교체 된 컨텐츠는 크기가 조정되지 않습니다.

### scale-down
내용이 없거나 포함되지 않은 것처럼 크기가 조정됩니다.  
(구체적인 객체 크기가 더 작아짐)
