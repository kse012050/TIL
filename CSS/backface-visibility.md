# backface-visibility
CSS의 사용자를 향할 때 소자(태그? 객체?)의 배면 표시 여벼 속성  

요소의 뒷면은 앞명의 거울 이미지입니다.  
2D에서는 보이지 않지만 변형으로 인해 요소가 3D 공간에서 회전하면 뒷면이 표시 될 수 있습니다.  
이 속성은 __투시가 없는 2D 변형__ 에는 영향을 미치지 않습니다.

## visible
default 값이며, 뒷면은 사용자쪽으로 향할 때 보입니다.

## hidden
뒷면이 숨겨져있어 사용자로부터 멀어 질 때 요소가 보이지 않게 합니다.
