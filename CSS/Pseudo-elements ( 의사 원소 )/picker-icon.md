# ::picker-icon
> __실험적: 실험적인 기술입니다.__  
> 실제 운영 환경에서 사용하기 전에 브라우저 호환성 표를 주의 깊게 확인하세요.  
  
__``::picker-icon``__ CSS 가상 요소는 연관된 아이콘이 있는 폼 컨트롤 내부의 피커 아이콘을 대상으로 합니다. 사용자 지정 가능한 select 요소의 경우, ``<select>`` 요소에 표시되는 화살표 아이콘(닫혔을 때 아래쪽을 가리키는 아이콘)을 선택합니다.

## Syntax
~~~css
::picker-icon {
    /* ... */
}
~~~

## Description
``::picker-icon`` 가상 요소는 폼 컨트롤의 피커 아이콘, 즉 컨트롤 버튼에 표시되는 아이콘을 대상으로 합니다. 원본 요소에 피커가 있고 ``appearance`` 속성의 ``base-select`` 값을 통해 기본 모양이 설정된 경우에만 대상으로 사용할 수 있습니다. 생성된 상자는 ``::after`` 가상 요소에 의해 생성된 상자 뒤에 기본 브라우저 스타일시트에 지정된 아이콘과 함께 나타납니다. ``content`` 속성을 사용하여 사용자 정의할 수 있습니다.  
  
``::picker-icon`` 선택자는 사용자 정의 가능한 select 요소의 인라인 끝 부분에 있는 아래쪽 화살표를 선택하는 데 사용할 수 있습니다. 이는 아이콘의 색상이나 크기를 사용자 정의하거나, 다른 아이콘(content 또는 SVG 사용)을 사용하거나, 피커를 열고 닫을 때 애니메이션을 적용하려는 경우에 유용합니다.  
  
현재 ``::picker-icon``은 사용자 정의 가능한 ``<select>`` 피커 아이콘을 선택하는 데만 사용할 수 있지만, 향후 더 많은 기능이 추가될 수 있습니다.  
  
> __참고__: ``::picker-icon`` 가상 요소는 접근성 트리에 포함되지 않으므로, 이 요소에 생성된 콘텐츠를 설정하더라도 보조 기술은 이를 인식하지 못합니다. 하지만 새로 설정하는 아이콘은 시각적으로 의도한 목적에 부합하는지 확인해야 합니다.

## Examples
### 피커 아이콘 애니메이션
사용자 지정 가능한 선택 기능을 사용하려면 ``<select>`` 요소와 피커 모두에 ``base-select``의 ``appearance`` 값이 설정되어 있어야 합니다.  
~~~css
select,
::picker(select) {
    appearance: base-select;
}
~~~

예를 들어 ``::picker-icon``을 대상으로 지정하고 사용자 지정 색상과 전환 효과를 적용하여 rotate 속성의 변경 사항이 부드럽게 애니메이션되도록 할 수 있습니다.

~~~css
select::picker-icon {
    color: #999;
    transition: 0.4s rotate;
}
~~~
다음 규칙에서 ``::picker-icon``은 :open 가상 클래스와 결합됩니다. :open 가상 클래스는 피커가 열려 있을 때만 아이콘을 대상으로 지정하며, ``<select>``가 열릴 때 회전 값을 180도로 전환합니다.

~~~css
select:open::picker-icon {
    rotate: 180deg;
}
~~~
이 코드를 사용하는 전체 예제와 라이브 예제 렌더링을 보려면 선택기 아이콘 스타일 지정을 참조하세요.
