# :focus-within
:focus-within CSS 의사 클래스는 요소 또는 그 하위 항목에 포커스가 있는 경우 요소와 일치합니다. 즉, :focus 의사 클래스와 일치하거나 :focus와 일치하는 하위 항목이 있는 요소를 나타냅니다. (여기에는 그림자 나무의 자손이 포함됩니다.)  
  
이 선택기는 사용자가 ``<input>`` 필드 중 하나에 초점을 맞출 때 전체 ``<form>`` 컨테이너를 강조 표시하는 일반적인 예를 들면 유용합니다.

## 문법
> :focus-within

## 예
자식 요소 중에 fouce 되는 요소가 있으면~~~
