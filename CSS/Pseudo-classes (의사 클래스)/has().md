# :has()
기능적 :has() CSS 의사 클래스는 인수로 전달된 상대 선택기 중 하나라도 이 요소에 고정될 때 하나 이상의 요소와 일치하는 경우 요소를 나타냅니다. 이 의사 클래스는 관대한 상대 선택자 목록을 인수로 취하여 참조 요소와 관련하여 상위 요소 또는 이전 형제 요소를 선택하는 방법을 제공합니다.

~~~css
/* 
    다음으로 h1 제목을 선택합니다.
    바로 뒤에 오는 단락 요소
    h1에 스타일을 적용하고 h1에 스타일을 적용합니다.
*/
h1:has(+ p) { margin-bottom: 0; }
~~~

``:has()`` 의사 클래스는 ``:is()`` 및 ``:not()``과 같은 방식으로 인수에서 가장 구체적인 선택자의 특이성을 취합니다.

번역 결과
상대 선택자 목록 매개변수는 관대합니다. 일반적으로 CSS에서 선택자 목록의 선택자가 유효하지 않으면 전체 목록이 유효하지 않은 것으로 간주됩니다. :has() 선택기 목록의 선택기가 구문 분석에 실패하면 올바르지 않거나 지원되지 않는 선택기가 무시되고 다른 선택기가 사용됩니다.  
  
:has() 의사 클래스 자체가 브라우저에서 지원되지 않으면 전체 선택기 블록이 실패합니다( :has() 자체가 :is() 및 :where(에서와 같이 허용되는 선택기 목록에 있지 않는 한). )).  
  
:has() 의사 클래스는 다른 :has() 내에 중첩될 수 없습니다. 또한 의사 요소는 :has() 내에서 유효한 선택자가 아닙니다. 이는 많은 의사 요소가 조상의 스타일에 따라 조건부로 존재하고 이러한 요소를 :has()로 쿼리하도록 허용하면 순환 쿼리가 도입될 수 있기 때문입니다. :has() 및 유사 요소는 유효하지 않은 :has() 선택기이지만 선택기 목록은 관대하므로 무시됩니다. 선택기는 실패하지 않습니다.

## 예제
### has().html 참고

이 예는 비교를 위해 두 개의 유사한 텍스트를 나란히 보여줍니다. 왼쪽 텍스트는 ``H1`` 머리글 다음에 단락이 있고 오른쪽 텍스트는 ``H1`` 머리글 다음에 ``H2`` 머리글과 단락이 있습니다. 오른쪽 예에서 ``:has()``는 ``H2`` 요소(인접한 형제 결합자``+``로 표시됨)가 바로 뒤에 오는 ``H1`` 요소를 선택하는 데 도움이 되며 CSS 규칙은 이러한 ``H1`` 요소 뒤의 간격을 줄입니다. :has() 의사 클래스가 없으면 CSS 선택기를 사용하여 다른 유형의 선행 형제 또는 상위 요소를 선택할 수 없습니다.
