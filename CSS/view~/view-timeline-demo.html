view-timeline

스크롤할 때 요소가 화면에 보이는 정도를 애니메이션 시간으로 쓰는 예제입니다. 아래 카드들이 들어오면 CSS 애니메이션이 같이 진행됩니다.

1. 단축 속성

`view-timeline`은 타임라인 이름과 축을 한 번에 정합니다. 이 카드가 화면에 들어오는 정도가 `--basic-reveal` 타임라인의 진행률이 됩니다. 

.basic-card{view-timeline: --basic-reveal block;}
.basic-card{animation-timeline: --basic-reveal;}

2. 속성 분해

같은 내용을 `view-timeline-name`, `view-timeline-axis`, `view-timeline-inset`으로 나누어 쓸 수 있습니다. 

.named-card{view-timeline-name: --named-reveal;}
.named-card{view-timeline-axis: block;}
.named-card{view-timeline-inset: 18% 12%;}
.named-card{animation-timeline: --named-reveal;}

3. 같은 타임라인 재사용

카드가 만든 `--axis-reveal` 타임라인을 안쪽 막대도 같이 사용합니다. subject는 카드이고, 애니메이션 대상은 카드와 막대 둘 다입니다. 

.axis-card{view-timeline: --axis-reveal block;}
.meter__bar{animation-timeline: --axis-reveal;}

다시 위로 스크롤하면 애니메이션 진행률도 되돌아갑니다.
