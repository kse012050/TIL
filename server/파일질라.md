## AWS (SFTP)
![AWS-SFTP 접속 정보 이미지](./images/AWS-SFTP01.PNG)
빨간색 영역 클릭  
  

![AWS-SFTP 접속 정보 이미지](./images/AWS-SFTP02.PNG)
1. 새로운 사이트 목록 생성
2. ``SFTP - SSH File Transfer Protocol`` 로 변경
3. 호스트 와 포트 입력 ( 1985 포트 : 22)
4. 로그인 유형 : ``키 파일`` 로 변경
5. 사용자명 입력 ( 1985 : ubuntu )
6. .pem 파일 연결
