# 이벤트 리스너
이벤트 리너스란 View 클래스 내에 있는 인터페이스로, 하나의 콜백 메서드가 포함되어 있습니다   
이러한 메서드는 리스너가 등록된 뷰가 UI안의 항목과 사용자의 상호작용으로 인하여   ```트리거```되었을 때 Android 프레임워크가 호출됩니다

## 이벤트 리스터 인터페이스에 포함된 콜백 메서드
### onClick()
[View.OnClickListener](https://developer.android.com/reference/android/view/View.OnClickListener.html?hl=ko) 에서 온 것입니다   
이 메서드는 사용자가 항목을 터치하거나 (터치 모드에 있을 때), 탐색 키 또는 ```트랙볼```을 사용하여 해당 항목에 포커스를 맞추고 적절한 'Enter' 키를 누르거나 트랙복을 누르면 호출 됩니다

### onLongClick()
[View.OnLongClickListener]() 에서 온 것입니다   
이 메서드는 사용자가 항목을 길게 누르거나(터치 모드에 있을 때), 탐색 키 또는 트랙볼을 사용하여 해당 항목에 포커스를 맞추고 적절한 'Enter'키를 누르거나 트랙볼을 누를 때 호출 됩니다

### onFocusChange()
[View.OnFocusChangeListener]() 에서 온 것입니다   
이것이 호출되는 것은 사용자가 탐색 키 또는 트랙볼을 사용하여 항목 쪽으로 이동하거나 항목에서 멀어질 때 입니다

### onKey()
[View.OnKeyListener]() 에서 온 것입니다
이 메서드는 사용자가 항목에 포커스를 맞추고 있으면서 기기에 있는 하드웨어 키를 누르거나 키에서 손을 떼면 호출됩니다

### onTouch()
[View.OnCreateContextMenuListener]() 에서 온 것입니다  
이것을 호출하는 것은 ```컨텍스트 메뉴```가 구출되는 중일 때 입니다(정체된 "길게 클릭"의 결과로)   
[메뉴]() 개발자 가이드에 있는 컨텍스트 메뉴 관련 논의 참조하세요

#### 모르는 용어 정리

```트리거``` :1. (직역) 총의 방아쇠   
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;2. 어느 특정한 동작에 반응해 자동으로 필요한 동작을 실행하는 것을 뜻합니다   

```트랙볼``` : 1. 볼마우스를 뒤집어 놓은 형태의 마우스

```컨텍스트 메뉴``` : 1. 그래픽 사용자 인터페이스 안에서 어떠한 항목을 클릭할 때 뜨는 팝업메뉴로, 메뉴를 호출한 동작, 응용 프로그램의 실행, 선택된 항목의 상황에 따라 다양한 선택사항을 나열하여 보여줍니다
