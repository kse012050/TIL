# HTML 텍스트 서식 지정
HTML은 특별한 의미로 텍스트를 정의하기 위한 텍벽한 요소를 정의합니다  

## 서식 요소는 특수한 텍스트 유형을 표시
~~~HTML
<b> - 굻은 텍스트
<strong> - 중요 텍스트 
<i> - 기울임 꼴 텍스트
<em> - 강조된 텍스트
<mark> - 표시된 텍스트
<small> - 작은 텍스트
<del> - 삭제 된 텍스트
<ins> - 삽입 된 텍스트
<sub> - 첨자 텍스트
<sup> - 위첨자 텍스트
~~~

### `<b>`
특별히 중요하지 않고 __굵게 표시된__ 텍스트를 정의합니다

### `<Strong>`
의미가 __"강한" 중요성이 추가된 강력한__ 를 정의합니다

### `<i>`
더 이상 중요하지 않고 *기울임* 꼴 텍스트를 정의합니다

### `<em>`
*강조된* 텍스트를 의미론적 중요성을 추가하여 정의합니다

### `<small>`
더 작은 텍스트를 정의 합니다


### `<mark>`
<mark>두드러진</mark> 또는 <mark>강조 표시된</mark> 텍스트를 정의 합니다
- 기본 옵션으로 background-color 라 노란색으로 깔립니다
- css를 통해 색상 변경이 가능합니다

### `<del>` 
~~삭제 된~~ (삭제) 텍스트를 정의합니다

### `<ins>`
<u>삽입 된</u> (추가된) 텍스트를 정의합니다

### `<sub>`
<sub>아래 첨자</sub> 텍스트를 정의합니다

### `<sup>`
<sup>위 첨자</sup> 텍스트를 정의합니다
