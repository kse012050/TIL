# 인용부호
~~~HTML
<q> - 짧은 인용문
<blockquote> - 다른 소스에서 인용 된 섹션을 정의합니다
<abbr> - 약어 또는 머리 글자를 정의합니다
<address> - 문서 또는 기사의 연락처 정보 ( 작성자 / 소유자)를 정의합니다
<cite> - 저작의 제목을 정의합니다
<bdo> - 양방향 재정의를 정의합니다
~~~

## `<q>`
브라우저는 대개 `<q>` 요소 주위에 __따옴표__ 를 삽입합니다  
주로 한 줄짜리 짧은 인용문에 쓰입니다

## `<blockquote>`
브라우저는 일반적으로 `<blockquote>` 요소를 들여 쓰기 합니다
+ html40.01 에서 blockquote 태그는 긴 인용문을 지정할 때 사용합니다
+ html5 에서 blockquote 는 다른 자원에서 인용한 일부를 지정할 때 사용합니다
> cite 속성  
 + blockquote는 cite 속성과 함께 사용할 수 있습니다
 + cite 속성은 인용문의 출처를 표시합니다  
    + 화면에서 특별히 표시되는 부분은 없지만  
    검색 엔진이 이 주소 정보를 사용할 수 있습니다
 

## `<abbr>`
마킹 약어는 브라우저, 번역 시스템 및 검색 엔진에 유용한 정보를 제공 할 수 있습니다
+ abbr 태그는 두문자어(acronym)와, 약어(abbreviation)에 사용하는 요소로, 브라우저나 검색엔진에 유용한 정보를 줍니다
    + 넷스케이프가 abbr 요소를 만들고, 마이크로소프트가 acronym을 만들어 두 요소 다 html4까지 사용하고 있었지만, 두 정의가 혼동스럽고 브라우저 지원도 저마다 달라, html5부터는 acronym은 퇴화 요소로 규정되었습니다
+ html5부터는 두문자어와, 약어에 모두 abbr 태그를 사용합니다
> acronym 두문자어  
>> 낱말의 머리글자를 모아서 만든 준말입니다  
한국어의 자민련, 노사모 등과 영어의 UN, NATO, DNA 등이 있습니다  

> abbreviation 약어
>> 준말 / 두 단어 이상으로 이루어진 표제어를 원말로 하여 각 단어에서 주로 한 음절씩 뽑아 만든 어휘  
쉽게 알아들을 수 있도록 줄인말. BBC 는 British Broadcasting Corporation의 축약어
+ 주로 __title__ 속성과 함께 사용합니다
    + title은 abbr에 대한 설명 문구입니다
+ abbr 태그는 firefox, opera에선 기본값으로 점선 밑줄로 표시 되며, ie8, safari, chrome은 스타일에 변화가 없습니다
    + 모든 브라우저에서 일관적으로 표시하도록 아래처럼 스타일링을 해주는 것이 좋습니다
~~~css
abbr{border-bottom:1px dotted black;}
~~~

## `<address>`
일반적으로 이탤릭체로 표시됩니다  
대부분의 브라우저는 요소 앞뒤에 줄 바꿈을 추가합니다

## `<cite>`
브라우저는 대개 이탤릭체로 요소를 표시합니다  
cite 태그는 cite 속성과 달리, 책, 영화, 그림 같은 작품의 제목을 지정할 때 사용 합니다  
+ html4.01에서 cite 태그는 인용구를 지정하는 역활을 했다면,
+ html5에서 cite는 작품의 제목을 지정합니다

## `<bdo>`
현재의 텍스트 방향을 무시하는 데 사용됩니다  
양방향 제어를 무시하고 __텍스트 방향을 지정__ 할 수 있게 합니다
+ dir 속성에 "rtl"(오른쪽에서 왼쪽방향으로) 또는 "ltr"(왼쪽에서 오른쪽방향으로) 값을 주면 텍스트 방향을 지정 할 수 있습니다

### `<bdi>`
히브리어, 아랍어 등과 같이 __오른쪽에서 왼쪽으로 흐르는 언어 군__ 이 필요할 때 사용하는 요소로 독립적인 양방향 텍스트 영역을 정의할 때 사용합니다
+ `<bdi>` 태그가 만병통치약은 아닙니다
+ 자동으로 텍스트방향을 제어하다보니 해석 오류로 인해 비정상적으로 출력 될 수가 있습니다
+ W3C에서는 `<bdi>` 즉, dir="auto" 설정은 텍스트의 방향성을 정말로 알 수가 없으므로, 서버 쪽에서 사용할 수 있는 더 좋은 알고리즘이 없을 때 __최후의 보루로 사용하기를 권장합니다__
    + 아라비아 문자 + 영어가 섞인 경우방향 제어 오류가 발생할 수 있습니다
        + 아라비아 문자(오른쪽에서 왼쪽) / 영어(왼쪽에서 오른쪽)


> + cite 속성과 ctie 태그의 사용 용도가 다릅니다 주의해주세요  
> + `<bdo>` 태그와 `<bdi>` 태그는 당장 사용할 일이 없습니다
