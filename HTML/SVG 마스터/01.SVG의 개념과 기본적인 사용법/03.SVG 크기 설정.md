# SVG 크기 설정

~~~html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta http-equiv="X-UA-Compatible" content="ie=edge">
    <title>SVG</title>
    <style>
    body{
        margin: 0;
    }
    svg{
        /* width: 500px;
        height: 500px; */
        background: #ddd;
    }
    </style>
</head>
<body>
    <!-- <svg width="500" height="500"> -->
    <svg viewBox="0 0 500 500">
        <rect x="0" y="0" width="100" height="100"></rect>
    </svg> 
</body>
</html>
~~~

## 원 그리기

~~~html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <script src="https://code.jquery.com/jquery-3.5.1.min.js" integrity="sha256-9/aliU8dGd2tb6OSsuzixeV4y/faTqgFtohetphbbj0=" crossorigin="anonymous"></script>
    <title>Document</title>
    <style>
        section svg{width: 210px; height: 210px;}
        svg circle{
            stroke-dasharray: 630;
            stroke-dashoffset: 630;
            animation: circleDraw 4s forwards;
        }
        @keyframes circleDraw {
            form{stroke-dashoffset: 630;}
            to{stroke-dashoffset: 0;}
        }
    </style>
</head>
<body>
    <section>
    <svg>
        <circle 
          cx="105" cy="105" r="100" 
          fill="none" stroke="#f9b10a" stroke-width="10" />
    </svg>
    </section>
    <script>
    <!-- svg 크기 가져오기 -->
        console.log(
            document.querySelector('circle').getTotalLength()
        )
        console.log(
            $('circle')[0].getTotalLength()
        )
    </script>
</body>
</html>
~~~


width의 값과 height의 값은 inline 방식이나 CSS로 지정해 줄 수 있습니다.  
여기서 중요한 것은 __viewBox__ 입니다.  
viewBox를 지정해주면 이미지태그 처럼 창의 크기에 따라 유동적으로 크기가 변환되고 viewBox 크기와 rect 테그의 크기는 비율에 따라 조정됩니다.
