# HTML 문서에 SVG를 넣는 여러가지 방법들
1. `<img>` 태그 
2. CSS Background
3. SVG 요소들을 직접 inline으로 삽입
4. `<object>` 태그

## `<img>` 태그 
~~~html
<img src="경로.SVG" alt="">
~~~
이미지 태그로 SVG 파일 불러오기가 가능합니다.

## CSS Background
~~~html
<div class="svg"></div>
<style>
background:url("경로.SVG") no-repeat 0 0;
</style>
~~~
CSS background로도 넣을 수 있다.

## SVG 요소들을 직접 inline으로 삽입
HTML 파일 안에 넣는 방식

## `<object>` 태그
~~~html
<object data="경로.svg" type="image/svg+xml">
~~~
이미지 태그와 같이 data에 경로를 써주면 됩니다.  
type은 기본적으로 __image/svg+xml__ 를 사용합니다.

이미지 태그와 다른점은 이미지 태그는 이미지 처럼들어가는 반면  
오브젝트 태그는 태그가 살아서 들어갑니다.
