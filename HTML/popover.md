# popover
``popover`` 전역 속성은 요소를 팝오버 요소로 지정하는 데 사용됩니다.  
  
팝오버 요소는 호출/제어 요소(예: ``<button>`` 또는 popovertarget 속성이 있는 ``<input type="button">``) 또는 HTMLElement.showPopover() 호출을 통해 열릴 때까지 디스플레이를 통해 숨겨집니다.  
  
열리면 팝오버 요소는 최상위 레이어의 다른 모든 요소 위에 표시되며 상위 요소의 위치 또는 오버플로 스타일에 영향을 받지 않습니다.  
  
팝오버 속성은 "auto"(기본값) 또는 "manual" 값을 가질 수 있습니다. 자동 상태의 팝오버는 팝오버 영역 외부를 선택하여 "간단하게 해제"될 수 있으며 일반적으로 한 번에 하나의 팝오버만 화면에 표시되도록 허용합니다. 대조적으로, 수동 팝오버는 항상 명시적으로 숨겨져야 하지만 메뉴의 중첩된 팝오버와 같은 사용 사례를 허용합니다.  
  
사용법에 대한 자세한 내용은 Popover API 랜딩 페이지를 참조하세요.

## 주의할 점
클릭되는 부분은 ``button`` 이어야 하고  
``popovertarget 속성``과 ``id 속성``으로 지정  
  
``popovertargetaction 속성``으로 이벤트 조절
- hide
- show
- toggle
