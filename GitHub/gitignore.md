# gitignore
gitignore- 의도적으로 추적되지 않은 파일을 무시하도록 지정

## 패턴 형식
- 빈 줄은 파일과 일치하지 않으므로 가독성을 위해 구분 기호로 사용할 수 있습니다.
- ``#`` 으로 시작하는 줄은 주석 역할을 합니다. ``\`` 해시로 시작하는 패턴의 경우 첫 번째 해시 앞에 백 슬래시 ("")을 넣어주세요.
- 후행 공백은 백 슬래시 ("``\``") 로 인용하지 않으면 무시됩니다.
- ``!`` 패턴을 무효화 하는 선택적 접두사 ""; 이전 패턴에서 제외 된 일치하는 파일은 다시 포함됩니다. 해당 파일의 상위 디렉토리가 제외 된 경우 파일을 다시 포함 할 수 없습니다. Git은 성능상의 이유로 제외된 디렉토리를 나열하지 않으므로 포함 된 파일의 패턴은 정의 된 위치에 관계없이 영향을 미치지 않습니다. 리터럴 ""로 시작하는 패턴(예:"``\``")의 경우 첫 번째 "``!``" 앞에 백 슬래시 ("")을 넣어주세요.
 > 무슨 말인지 모르겠습니다.
- 슬래시 (/)는 디렉토리 구분 기호로 사용됩니다. ``.gitignore`` 검색 패턴의 시작,중간 또는 끝에서 구분 기호가 발생할 수 있습니다.
- 패턴 시작 또는 중간(또는 둘 다)에 구분 기호가 있는 경우 패턴은 특정 ``.gitignore`` 파일 자체의 디렉토리 레벨을 기준으로 합니다. 그렇지 않으면 패턴이 레벨 아래의 어떤 레벨에서도 일치 할 수 있습니다. 
- 예를 들어, 패턴 ``doc/frotz/`` 은 ``doc/fortz`` 디렉토리와 일치 하지만 ``a/doc/frotz`` 디렉토리와 일치 하지 않습니다. 그러나 ``frotz/``는 ``frotz`` 하고 ``a/frotz``와 일치하는 디렉토리 입니다. (모든 경로는 ``.gitignore`` 파일과 관련이 있습니다.)
> 상대경로?
- 별로 ``"*"``는 슬래시를 제외한 모든 항목과 일치합니다. ``"?"`` 문자는 ``"/"`` 을 제외한 모든 문자와 일치합니다. 예를 들어 ``[a-zA-Z]`` , 범위 표기법을 사용하여 범위의 문자 중 하나를 일치시킬 수 있습니다.
