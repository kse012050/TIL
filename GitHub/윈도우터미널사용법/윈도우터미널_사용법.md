# 터미널 명령어

## cd [폴더이름]
드라이브 변경하는 방법
> $ E: , $ D: , $ E:  

해당 디렉토리(폴더)로 이동합니다
>$ cd documents﻿
``` 현재폴더의 하위폴더인 documents 폴더로 이동```

>$ cd /c/workspace﻿
``` 절대경로 /c/폴더 이름 로 이동```

>$ cd ..
``` 상위 폴더로 이동```

## mkdir [폴더이름]  ( make directory )
디렉토리(폴더)를 생성합니다
>$ mkdir 폴더이름  

``` 현재폴더에 [폴더이름] 폴더를 생성```

## touch[파일이름]
빈 파일을 생성합니다
>$ touch 파일이름.확장자 ex) index.js / index.md  

``` 현재폴더에 파일이름.확장자 파일을 생성합니다```

## Is ( list segments )
현재 디렉토리 안에 있는 파일및 폴더들을 보여줍니다
### ls -al
현재 디렉토리(폴더) 안에 있는 모든 파일 및 폴더를 보여 줍니다.

## rm ( remove )
### rm -rf [파일명] ( resursive force )
[파일]을 삭제한다
